# noveltool

小説の執筆ツール。ブラウザで開くだけで使えます（インストール不要・サーバー不要）。

## できること

- **作品 ＞ 話** の2階層で原稿を管理（話の並べ替え・削除、作品名の変更）
- **文字数表示**：この話の文字数と作品全体の文字数（サイドバーには話ごとの文字数も表示）
  - 数えるのは画面に表示される本文の文字だけです。ルビの読み、`｜《》` などの記号、空白、改行は数えません。
- **カクヨム記法のプレビュー**
  | 書き方 | 表示 |
  |---|---|
  | `｜漢字《かんじ》`（`|` 半角でも可） | ルビ |
  | `漢字《かんじ》` | 漢字の直後ならルビ（`｜` を省略できる） |
  | `《《強調》》` | 傍点 |
  | `｜《` | `《` をそのまま表示 |
- **横書き／縦書きプレビュー**（縦書きでは半角2桁の数字と `!?` `!!` を縦中横で表示）
- 「並べて」表示（広い画面のみ）：書きながら右側でプレビュー
- 「ルビ」「傍点」ボタン：選択した文字に記号を付けます（スマホで `｜《》` を打つのが大変なとき用）
- **自動保存**：入力して少し経つと、ブラウザ内（localStorage）に自動保存。`Ctrl+S` / `⌘S` ですぐ保存
- **書き出し・読み込み**
  - 「全原稿を書き出し」：全作品をひとつの `.txt` にまとめて保存
  - 作品を開いて「この作品を書き出し」：その作品だけを保存
  - 「テキストを読み込み」：書き出したファイルを「追加」または「すべて置き換え」で取り込み。普通のテキストファイル（UTF-8 / Shift_JIS）は「1作品・1話」として取り込みます
- スマホ対応：☰ ボタンで作品一覧を開閉

### 資料ビューア

執筆画面の右側に、設定資料やプロットなどの Markdown（`.md`）ファイルを表示できます。

- 「＋ 読み込み」で複数の `.md` ファイルをまとめて読み込み（パネルへのドラッグ＆ドロップでも可）。同じ名前のファイルを読み込むと上書きします
- 上部のファイル名をタップすると資料の一覧が開き、切り替えや削除ができます
- 「目次」で見出しの一覧を表示。項目を押すとその見出しへ移動し、いま読んでいる見出しが強調されます
- 原稿と資料の境目をドラッグして幅を変更（ダブルクリックで元の幅に戻ります。キーボードの ← → でも調整可）
- 右上の「資料」ボタンで資料パネルの表示／非表示を切り替え
- スマホでは画面上部の「原稿」「資料」タブで切り替え
- 表示に対応している Markdown：見出し、段落、箇条書き（入れ子・番号・チェック）、表、引用、コード、太字・斜体・取り消し線、リンク、区切り線。カクヨム記法のルビ・傍点も表示されます

資料は原稿とは別に、ブラウザ内（IndexedDB）に保存されます。**リポジトリにも、原稿の書き出しファイルにも含まれません。**元のファイルは手元に残しておいてください。
リポジトリのフォルダ内に資料を置く場合は、`資料/` `refs/` `notes/` のどれかに入れれば `.gitignore` によりコミットされません。

### 注意：原稿の保存場所

原稿は **使っているブラウザの中だけ** に保存されます。サーバーには送られません。

- パソコンとスマホなど、別の端末とは自動で同期されません。書き出したファイルを読み込んで移してください。
- ブラウザの「閲覧データを削除」をすると原稿も消えます。**ときどき「全原稿を書き出し」でバックアップ** を取ってください。
- iPhone / iPad の Safari は、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります。

### 書き出しファイルの形式

```
#noveltool v1
=====作品：作品名
-----話：第1話
本文……
-----話：第2話
本文……
```

本文の行が `=====作品：` や `-----話：`、`\` で始まる場合は、先頭に `\` を付けて書き出します（読み込むときに元に戻ります）。

## 手元で使う

このフォルダの `index.html` をブラウザで開くだけで動きます。

## GitHub Pages で公開する手順

1. このブランチの変更を `main` に取り込みます（プルリクエストを作って Merge する）。
2. GitHub でリポジトリを開き、**Settings** → 左メニューの **Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** で `main`、フォルダで `/ (root)` を選び、**Save** を押します。
5. 1〜2分待ってページを再読み込みすると、上部に公開URLが表示されます。
   通常は `https://<ユーザー名>.github.io/noveltool/` です。
6. スマホではそのURLを開き、共有メニューから「ホーム画面に追加」するとアプリのように使えます。

補足：

- 無料プランで Pages を使うには、リポジトリを **Public（公開）** にする必要があります。公開されるのはツールのプログラムだけで、書いた原稿はブラウザの中にあるため、ほかの人からは見えません。
- ツールを更新したときは、`main` に変更を取り込めば自動で公開ページにも反映されます。
- 公開URLが変わると保存場所も変わります（ブラウザはURLごとに保存するため）。URLを変えるときは先に書き出してください。
