# noveltool

小説の執筆ツール。ブラウザで開くだけで使えます（インストール不要・サーバー不要）。

## できること

- **作品 ＞ 章 ＞ 話** の3階層で原稿を管理（カクヨムの章と同じ扱い。詳しくは下の「章と話」）
- **作品タブ**：画面上部に作品ごとのタブが並び、クリックで切り替え。「＋」で新しい作品
  - 作品ごとにURLが分かれています（例：`index.html?work=作品ID`）。タブを **Ctrl／⌘＋クリック**（または中クリック）すると、ブラウザの別タブで開けます。ブックマークもできます
- **文字数表示**：話ごと・章ごと・作品全体の文字数（上部に「この話／この章／作品計」、サイドバーに話ごと・章ごとの文字数）
  - 数えるのは画面に表示される本文の文字だけです。ルビの読み、`｜《》` などの記号、空白、改行は数えません。
- **カクヨム記法のプレビュー**
  | 書き方 | 表示 |
  |---|---|
  | `｜漢字《かんじ》`（`|` 半角でも可） | ルビ |
  | `漢字《かんじ》` | 漢字の直後ならルビ（`｜` を省略できる） |
  | `《《強調》》` | 傍点 |
  | `｜《` | `《` をそのまま表示 |
- **横書き／縦書きプレビュー**（縦書きでは半角2桁の数字と `!?` `!!` を縦中横で表示）
- 「並べて」表示（広い画面のみ）：書きながら右側でプレビュー
- 「ルビ」「傍点」ボタン：選択した文字に記号を付けます（スマホで `｜《》` を打つのが大変なとき用）
- **自動保存**：入力して少し経つと、ブラウザ内（IndexedDB）に自動保存。`Ctrl+S` / `⌘S` ですぐ保存
- **書き出し・読み込み**（作品ごとに本文だけ。詳しくは下の「書き出しと読み込み」）
- **表記ゆれチェック**：作品ごとの用語辞書と人物事典をもとに、表記ゆれ・初出のルビ漏れ・よくあるゆれを一覧にし、確認しながら置換（詳しくは下の「表記ゆれチェック」）
- スマホ対応：☰ ボタンで話の一覧を開閉

### 章と話

- 章は任意です。章に入れない話（**章なし**）は、カクヨムと同じく章より前に並びます。今までの話はすべて「章なし」としてそのまま引き継がれます
- サイドバー下の「＋ 章を追加」で章を作成。章の「⋯」から **名前を変更／この章に話を追加／前へ・後ろへ（章の並べ替え）／章を削除**
- 章を削除するときは、中の話を **「章なし」に移す** か **一緒に削除する** かを選べます
- 話の左の **⋮⋮ をドラッグ** すると、話の並べ替えや別の章への移動ができます（スマホでも指でドラッグできます）。閉じている章の見出しに重ねると、その章の最後に入ります
- 執筆画面上部の ↑↓ でも移動できます（章の先頭・末尾では前後の章へ移ります）。章の選択欄で、話を別の章の最後へ移すこともできます
- 章の見出しの ▾ で章を折りたためます
- 「＋ 話を追加」は最後の章の末尾に追加します（章の「⋯」から、その章に追加することもできます）

### 書き出しと読み込み

サイドバーの「この作品を書き出し…」で、開いている作品の **本文だけ** を書き出します（資料は含みません。資料は元の `.md` ファイルを手元に残しておいてください）。ルビや傍点はカクヨム記法のまま残ります。形式は2つから選べます。

1. **1話ずつ別々のテキストファイル（ZIP）**
   ```
   作品名.zip
   └ 作品名/
     ├ 作品名_001_プロローグ.txt        ← 章なしの話
     ├ 01_第一章　旅立ち/
     │ ├ 作品名_002_出会い.txt
     │ └ 作品名_003_別れ.txt
     ├ 02_第二章/
     │ └ 作品名_004_再会.txt
     └ noveltool.json                  ← 章と話の構成（読み込み用）
   ```
   - 話番号は作品全体の通し番号です。ファイルの中身は本文だけなので、そのまま投稿画面に貼り付けられます
   - ファイル名に使えない記号（`/ \ : * ? " < > |`）は `_` に置き換わります。元のタイトルは `noveltool.json` に残るので、読み込むと元どおりになります
2. **作品全体を1つのテキストファイル**
   ```
   #noveltool v3
   【作品】作品名
   【作品ID】作品のID

   【話】プロローグ
   本文……

   【章】第一章　旅立ち

   【話】出会い
   本文……

   ```
   - 本文の行が `【作品】` `【作品ID】` `【章】` `【話】` `\` のどれかで始まるときは、先頭に `\` を付けて書き出します（読み込むときに元に戻ります）

**読み込み**：サイドバー下の「書き出したファイルを読み込み」で、①の ZIP または ②のテキストファイルを選ぶと、章と話の構成ごと復元します。ZIP を展開したフォルダは「書き出したフォルダ…を読み込み」で読み込めます。

- 同じ作品（作品IDが同じ）がすでにあるときは、「上書きする」（章と話を置き換え。資料はそのまま）か「別の作品として追加する」かを選べます
- `noveltool.json` がない ZIP やフォルダも、フォルダ名を章、ファイル名を話として読み込みます（先頭の番号順に並べます）。Windows や Mac で圧縮し直した ZIP も読み込めます
- 以前の書き出し形式（`#noveltool v1` / `v2`）や、普通のテキストファイル（UTF-8 / Shift_JIS。1作品・1話として取り込み）も読み込めます

### 資料ビューア

執筆画面の右側に、設定資料やプロットなどの Markdown（`.md`）ファイルを表示できます。

- **資料は作品ごと**に管理されます。作品を切り替えると、資料の一覧もその作品のものに切り替わります
- 読み込み方
  - 「＋ 読み込み」：複数の `.md` ファイルをまとめて選択
  - 一覧の「フォルダを選ぶ」：フォルダの中（サブフォルダも含む）の `.md` をまとめて読み込み
  - 資料パネルへファイルやフォルダをドラッグ＆ドロップ
  - **同じファイル名を読み込むと上書き更新**されます（改稿した資料を入れ直すときに便利です）
- 上部のファイル名を押すと資料の一覧が開き、切り替えができます
- 削除：一覧のチェックボックスで選んで「選択した資料を削除」、または「この作品の資料をすべて削除」。どちらも削除前に確認が出ます（元のファイルは消えません）
- 「目次」で見出しの一覧を表示。項目を押すとその見出しへ移動し、いま読んでいる見出しが強調されます
- 原稿と資料の境目をドラッグして幅を変更（ダブルクリックで元の幅に戻ります。キーボードの ← → でも調整可）
- 右上の「資料」ボタンで資料パネルの表示／非表示を切り替え
- スマホでは画面上部の「原稿」「資料」タブで切り替え
- 表示に対応している Markdown：見出し、段落、箇条書き（入れ子・番号・チェック）、表、引用、コード、太字・斜体・取り消し線、リンク、区切り線。カクヨム記法のルビ・傍点も表示されます

資料は **リポジトリには含まれません**（ブラウザ内にだけ保存されます）。リポジトリのフォルダ内に資料を置く場合は、`資料/` `refs/` `notes/` のどれかに入れれば `.gitignore` によりコミットされません。

### 表記ゆれチェック

右側のパネルの「表記チェック」タブで使います（スマホは「資料・チェック」タブ）。

- **用語辞書**（作品ごと）：「＋ 用語を追加」で **正しい表記・ゆれやすい表記（「、」区切りで複数）・ルビ・メモ** を登録します
- **人物事典の名前・別名**も辞書として使います（下の「人物事典との連携」）。名前・別名はどれも正しい表記として扱います
- **チェック**：範囲（この話／この章／作品全体）を選んで「チェックする」。見つかったものを種類ごとに一覧にします。各行を押すと、その話のその箇所へ移動して選択します
  - **登録した表記ゆれ**：辞書の「ゆれやすい表記」が使われている箇所
  - **辞書にない表記ゆれの候補**：辞書の語・人物名に近いのに辞書にない表記（異体字の「渡邊」→「渡辺」、カタカナの1文字違い・長音や小さい字の違い、3文字以上の漢字語の1文字違いなど）。「無視」で今後は出さない、「ゆれとして登録」で辞書に追加できます
  - **初出でルビがない用語**：ルビを登録した用語・人物名が、最初に出てくるところでルビなしになっている箇所。「ルビを付ける」で `｜用語《ルビ》` を入れます（「設定」で、作品全体での初出か、話ごとの初出かを選べます）
  - **よくある表記ゆれ**：「設定」でチェックしたものだけを調べます（「（〜と）いう／言う」「とき／時」「こと／事」「ところ／所」「もの／物」「できる／出来る」「わかる／分かる／判る」「ください／下さい」「すべて／全て」など。統一先をどちらにするかも選べます）
- **置換**：各項目の「置換…」で該当箇所がチェック付きで並ぶので、**置換する箇所を1件ずつ選んで** から実行します。「検索して置換」で、好きな語を探して同じように置換することもできます
  - 置換の直後は「元に戻す」で取り消せます
  - 別のタブで編集中の話は置換しません（件数をお知らせします）
- 辞書と設定はこのブラウザ内に作品ごとに保存されます（書き出しファイルには含まれません）

### 人物事典との連携

人物事典（作成中の別ツール）が同じ公開ページ（同じURLの配下）にあれば、その名前・別名を自動で読み込みます（読むだけで、人物事典のデータは書き換えません）。人物事典がなければ、用語辞書だけで動きます。

人物事典ツール側は、次の形で保存してあれば読み込めます。

- IndexedDB のデータベース名：`noveltool-people`
- オブジェクトストア `people`（または `persons` / `characters`）：1人1レコード
  | 項目 | 内容 |
  |---|---|
  | `name` | 名前（必須） |
  | `aliases` | 別名（文字列の配列、または「、」区切りの文字列） |
  | `ruby` | 名前の読み（初出のルビ漏れチェックに使う。任意） |
  | `variants` | よくある誤記（任意。あれば「登録した表記ゆれ」として指摘） |
  | `workId` | 人物事典側の作品ID（任意） |
- オブジェクトストア `works`（任意）：`{ id, title }`。人物に `workId` があるときは、執筆ツールの作品と **同じ名前の作品** の人物を使います（用語辞書の「使う人物事典の作品」で選び直せます）
- 変更したときに `BroadcastChannel('noveltool-people')` へ何か送ると、開いている執筆ツールがすぐ読み直します（送らなくても、タブを切り替えて戻ったときに読み直します）

### 別のタブで同時に開いたとき

- 作品や話はそれぞれ別々に保存されるので、別のタブで別の作品・別の話を書いても、互いに上書きしません。
- **同じ話**を2つのタブで開くと、あとから開いたタブは読み取り専用になります（もう一方のタブで書いた内容はすぐに反映されます）。「このタブで編集する」を押すと編集をこちらに移せます。
- 万一、同じ話が2つのタブから保存された場合も、片方を消さずに「（別タブで保存された版）」という別の話として残します。
- 資料の読み込み・削除も、同じ作品を開いている他のタブにすぐ反映されます。

### 保存場所と容量

原稿と資料は **使っているブラウザの中（IndexedDB）だけ** に保存されます。サーバーには送られません。
IndexedDB は以前の保存先（localStorage、約5MB）より大きな容量を使えます。サイドバーの下に現在の使用量が表示されます。

- 以前の版で書いた原稿と資料は、初めて開いたときに自動で新しい保存先へ移されます（以前の資料は、そのとき開いていた作品に登録されます）。元のデータも念のためブラウザ内に残してあります。
- パソコンとスマホなど、別の端末とは自動で同期されません。原稿は作品ごとに書き出したファイルを読み込んで、資料は元の `.md` ファイルを読み込み直して移してください。
- ブラウザの「閲覧データを削除」をすると原稿も消えます。**ときどき書き出してバックアップ** を取ってください。
- iPhone / iPad の Safari は、しばらく開かないサイトのデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります。

## 年表ツール（`timeline/`）

四部構成のミステリーなど、**起点までは共通の時間軸・起点からは部ごとにルートが分かれる** 作品のための年表です。執筆ツールとは別のページで、データも別々に保存されます。執筆ツールのサイドバー下の「年表ツールを開く」、または `timeline/index.html`（公開ページなら `https://<ユーザー名>.github.io/noveltool/timeline/`）から開きます。

### 設定（作品ごと）

- 「＋ 新しい年表」または「設定」で、**作品名・起点の日付（時刻は任意）・部** を決めます。部は最初に第一部〜第四部が入っていて、追加・名前の変更・色・並べ替え・削除ができます
- 部ごとに **描いている期間**（始まり・終わり）を入れると、年表の日付の横に色帯で表示されます。終わりを空けると「その日以降ずっと」になります
- 起点の時刻を決めた場合、起点の日のその時刻より前（時刻を入れたできごと）は共通、それ以外は起点以降として扱います

### できごとの入力

- 「＋ できごと」で、日付（カレンダーから選択・曜日も表示）、時刻（任意）、できごと、登場人物（複数）、場所、関連する話（任意）、メモを入れます
- 日付が **起点より前** なら共通のできごとになり、**どの部で描写するか** にチェックします（複数可）。部ごとに細かく違う点は、チェックした部の「補足」に書けます
- 日付が **起点以降** なら、**どの部のルートか** を選びます（複数可）
- 同じ日時のできごとはいくつでも登録できます。「同じ日時でもう1件」で、日時・人物・場所・部を引き継いで続けて入力できます
- 一度入れた人物・場所・関連する話は候補に出ます（人物は入力欄の下の候補を押しても追加できます）
- 表の空いているところをダブルクリックすると、その日時（と列の部・人物）で新しいできごとを作れます。できごとを押すと編集・削除できます

### 表示

- 縦に日付が並ぶ表です。同じ日のできごとは同じ行に時刻順に並び、各列のカードの上端がそろいます（時刻はカードに表示）。起点の日は、起点の前と後で行が分かれます
- 期間の始まり・終わりの日には、日付の下に「第一部 ここから／ここまで」と表示されます
- **部ごと**（「列」→「部ごと」）
  - 部ごとの列に、カードを見出しの真下に並べます（列の幅＝カードの幅）
  - 起点より前の共通のできごとは「描写する部」にチェックした部の列に、起点以降はルートの部の列に入ります
  - 複数の部にまたがるできごとは、それぞれの部の列に同じカードを表示します。部ごとの補足は、その部の列のカードにだけ出ます（ほかの部は「ほかに」の印で表示）
  - どの部も選んでいない（未割り当て）できごとは、日付のすぐ右の細い「共通」列に入ります
  - その部が描いていない期間は、列が薄いグレーになります
- 「表示」で部を選ぶと、**その部で描写するできごと＋その部のルート** だけを通しで表示します（その部の補足も表示）
- **人物ごと**（「列」→「人物ごと」）
  - 「設定」の「『人物ごと』表示で列にする人物」でチェックした人物だけを、その順に左から列にします（↑↓で並べ替え）。作品ごとに選べます
  - 選んだ人物が関わらないできごとは、右端の「その他」列に入ります
  - 選んだ人物が複数関わるできごとは、それぞれの列に表示します
  - どのカードにも、関わっている全員の名前をタグで表示します（列にしていない人物も含む。列にしている人物は色付き）
  - 日付の横の色帯で、各部の描いている期間がわかります
- 「絞り込み」で人物（複数選択可）・場所を絞り込めます（どちらの表示でも使えます）
- 横にスクロールしても、日付（と色帯）の列と見出しは固定されます

### 保存・書き出し・読み込み

- データはこのブラウザ内（IndexedDB の `noveltool-timeline`）にだけ保存され、リポジトリには含まれません
- 「MD書き出し」「CSV書き出し」で、開いている年表を作品単位で書き出します。「読み込み」で書き出したファイルを選ぶと復元できます。同じ年表（年表IDが同じ）がすでにあるときは「上書きする」か「別の年表として追加」かを選べます
- MDは読みやすい形（共通のできごと → 起点 → 起点以降）で、そのまま資料としても使えます。書き出したMDを書き換えてから読み込むこともできます

### 年表のCSV（読み込み用の書式）

表計算ソフトで作ったCSVを読み込んで、年表を作ることもできます。記入例：[`timeline/sample.csv`](timeline/sample.csv)

- 文字コードは UTF-8（BOM の有無はどちらでも）。Excel で保存した Shift_JIS も読み込めます
- **1行目は見出し** です。列の順番は自由で、使わない列は省略できます（「日付」「できごと」は必須）

  | 列 | 内容 |
  |---|---|
  | 種別 | `年表` / `部` / `できごと`。空欄はできごととして扱います |
  | ID | 空欄でかまいません（書き出したファイルでは元に戻すために入っています） |
  | 日付 | `2025-04-01` または `2025/4/1` |
  | 曜日 | 書き出し時に入ります。読み込みでは使いません（空欄可） |
  | 時刻 | `9:00` / `21:30` など。空欄可 |
  | できごと | できごとの内容。種別が `年表` なら作品名、`部` なら部の名前 |
  | 登場人物 | 複数は `、` で区切る（例：`人物A、人物B`）。種別が `年表` なら、列にする人物 |
  | 場所 | |
  | 関連する話 | 任意 |
  | 区分 | 書き出し時に `共通` / `ルート` が入ります。読み込みでは使いません（日付と起点から自動で決まります） |
  | 部 | 起点より前なら **描写する部**、起点以降なら **ルートの部**。複数は `、` で区切る |
  | 部ごとの補足 | `【第一部】補足の文` の形。複数の部はセル内で改行して続けます |
  | メモ | 改行を含めてかまいません |
  | 期間の終了 | 種別が `部` の行だけ：描いている期間の終わりの日 |
  | 色 | 種別が `部` の行だけ：`#c0504d` のような色 |

- 行の種類
  - `年表` の行（1行）：「できごと」に作品名、「日付」「時刻」に **起点**、「登場人物」に「人物ごと」表示で **列にする人物**（`、` 区切り・この順に並ぶ。省略可）
  - `部` の行（部の数だけ。この順に並びます）：「できごと」に部の名前、「日付」に描いている期間の始まり、「期間の終了」に終わり、「色」
  - `できごと` の行：上の表のとおり
- `年表` の行がないときは作品名が「読み込んだ年表」、起点がいちばん早いできごとの日になります（あとで「設定」で直せます）。`部` の行がなくても、「部」の列に出てくる名前から部を作ります
- 値にカンマ・改行・`"` を含むときは、セル全体を `"` で囲み、中の `"` は `""` と書きます（表計算ソフトで保存すれば自動でそうなります）

## 配置図ツール（`map/`）

城や屋敷、町などの配置図を方眼の上に描くツールです。執筆ツール・年表ツールとは別のページで、データも別々に保存されます。執筆ツールのサイドバー下の「配置図ツールを開く」、年表ツールの上部の「配置図」、または `map/index.html`（公開ページなら `https://<ユーザー名>.github.io/noveltool/map/`）から開きます。

### 作品と地図

- 「＋ 新しい作品」で作品を作り、**連動する年表**（年表ツールの年表）を選びます。あとから「作品の設定」で変えられます
- 1つの作品に地図を何枚でも作れます（例：「城全体図」「表御殿の中」）。左の一覧で切り替えます。リンクでつながった地図は入れ子で表示されます
- 「地図の設定」で、名前・広さ（横×縦のマス数）・**縮尺（1マス＝◯m）**・階を設定します。地図の下にものさしが出ます
- **複数階**：「＋ 階」または「地図の設定」で階を足し、地図の上のボタンで描く階を切り替えます。ひとつ下の階が薄く表示されるので、位置を合わせやすくなっています

### 描き方

| 道具 | 使い方 |
|---|---|
| 選択 | 図形を押して選択、ドラッグで移動。角の丸で大きさ変更、上の丸で回転（15度ごと。Shift を押しながらだと自由に） |
| 四角 | ドラッグで建物・部屋を描く（押しただけなら 4×3 マス） |
| 多角形 | 角を順に押し、最初の点を押す（またはダブルクリック・Enter）で完成。Backspace で1点戻す |
| 線 | 道・塀・壁・堀・川・柵などを、点を順に押して描く。最後の点をもう一度押すか Enter で完成 |
| 記号 | 門・扉・階段・井戸・木・目印を置く（大きさ・向きも変えられます） |
| ものさし | ドラッグで2点の距離を縮尺どおりの m で表示 |

- 選んだ図形は、右の欄で **名前・色・メモ**、四角の大きさ（マス・m・㎡ を表示）、線の種類・太さ、記号の種類などを変えられます。複製・前面へ・背面へ・削除もここから
- **詳しい地図へのリンク**：建物（四角・多角形・記号）の「リンク先の地図」を選ぶと、その建物を **ダブルクリック** するか「◯◯を開く」でその地図へ移ります。「＋ 新しい地図を作ってリンク」で、中の地図をその場で作れます。戻るときは地図の上の「← 元の地図」
- 「吸着」で方眼に合わせる細かさ（なし／½マス／1マス）を選べます
- 何もないところをドラッグで地図を動かし、ホイール（スマホは2本指）で拡大縮小。「全体」で地図全体を表示
- 元に戻す・やり直す：↶ ↷ ボタン、または `Ctrl+Z`／`Ctrl+Shift+Z`（Mac は ⌘）。ほかに `Delete` で削除、`Ctrl+D` で複製、矢印キーで少しずつ移動、`V R P L S M` で道具の切り替え

### 年表との連動

- 左の「年表の場所」に、連動する年表に登録された場所（できごとの件数つき）が出ます。「置く」を押してから地図を押すか、地図へドラッグすると、**場所のピン** を置けます。建物の「年表の場所」に名前を入れて、建物そのものを場所にすることもできます
- 地図の上のピンや、場所を設定した建物を押すと、右の欄に **その場所が登録されているできごとの一覧** が出ます。「部で絞り込み」で部ごとに見られます
- 地図に置いてある場所には「●地図あり」と出ます。一覧で名前を押すと、その場所を表示します
- 年表ツールのデータは読むだけで、配置図ツールから書き換えることはありません

### 保存・書き出し・読み込み

- データはこのブラウザ内（IndexedDB の `noveltool-map`）にだけ保存され、リポジトリには含まれません
- 「JSON書き出し」で、開いている作品の地図をすべて1つの JSON ファイルに書き出します。「読み込み」で選ぶと復元できます。同じ作品（作品IDが同じ）がすでにあるときは「上書きする」か「別の作品として追加」かを選べます。連動する年表は、年表のID、なければ年表の名前で探してつなぎ直します
- 「PNG保存」で、表示中の地図（表示中の階）を画像で保存します

### 配置図のJSON（読み込み用の書式）

手で書いた JSON や、ほかのツールで作った JSON も読み込めます。記入例：[`map/sample.json`](map/sample.json)（年表の記入例 [`timeline/sample.csv`](timeline/sample.csv) と同じ場所名を使っているので、両方読み込むと連動のようすを試せます）

```json
{
  "format": "noveltool-map",
  "version": 1,
  "work": { "id": "my-castle", "title": "作品名", "timelineTitle": "連動する年表の名前" },
  "maps": [
    {
      "id": "castle", "name": "城全体図", "width": 48, "height": 36, "scale": 4,
      "floors": [{ "id": "f1", "name": "地上" }],
      "shapes": [
        { "type": "rect", "x": 12, "y": 10, "w": 14, "h": 9, "name": "表御殿", "color": "#ead9b5" },
        { "type": "line", "kind": "moat", "points": [[4, 4], [44, 4], [44, 32]], "name": "外堀" },
        { "type": "symbol", "kind": "gate", "x": 24, "y": 29, "name": "大手門" },
        { "type": "pin", "x": 36, "y": 26, "place": "年表の場所の名前" }
      ]
    }
  ]
}
```

- 座標・長さの単位は **マス**（左上が `0, 0`、右・下へ増える）。m にするには `scale`（1マス＝何m）を掛けます
- `work`：`title` 作品名（必須）。`id` を書くと、同じIDの作品があるとき上書きできます。`timelineWorkId`（年表のID）か `timelineTitle`（年表の名前）で連動する年表を指定します（どちらも省略可）
- `maps`：地図の配列（1枚以上）

  | 項目 | 内容 |
  |---|---|
  | `id` | 地図のID（このファイルの中で別々に。リンク先の指定に使う）。省略すると `map1`, `map2`… |
  | `name` | 地図の名前 |
  | `width` / `height` | 横・縦のマス数（5〜500。省略すると 40×30） |
  | `scale` | 1マスが何m か（省略すると 1） |
  | `floors` | 階の配列 `{ "id", "name" }`。**下の階から順に**。省略すると1階だけ |
  | `shapes` | 図形の配列（下の表）。後ろにあるものほど上に重なります（ピンは常にいちばん上） |

- 図形（`shapes`）の項目。どの図形にも `name`（名前）・`memo`（メモ）・`floor`（階の `id`。省略すると最初の階）を書けます

  | `type` | 項目 |
  |---|---|
  | `rect`（四角） | `x` `y`（左上）、`w` `h`（横・縦）、`rot`（回転の角度。中心まわり・時計回り）、`color`、`link`、`place` |
  | `poly`（多角形） | `points`：角の座標 `[[x, y], …]`（3つ以上）、`color`、`link`、`place` |
  | `line`（線） | `points`：点の座標（2つ以上）、`kind`：`road`（道）・`wall`（塀・壁）・`moat`（堀）・`river`（川）・`fence`（柵・生け垣）・`other`、`width`（太さ・マス。省略で種類のめやす）、`color`（省略で種類の色） |
  | `symbol`（記号） | `kind`：`gate`（門）・`door`（扉）・`stairs`（階段）・`well`（井戸）・`tree`（木）・`star`（目印）、`x` `y`（中心）、`size`（大きさ・マス。省略で 1.5）、`rot`、`link`、`place` |
  | `pin`（年表の場所） | `place`：年表の場所の名前（必須）、`x` `y`（ピンの先） |

  - `color` は `#ead9b5` のような色。`link` はリンク先の地図の `id`（地図の `name` でも可）。`place` は年表に登録した場所の名前
  - 図形の `id` は省略できます（読み込むと作られます）
- 読み込むと、地図のIDは新しく作り直されます（リンクは自動で付け替えます）

## 人物事典（`people/`）

登場人物の設定と、**誰が誰をどう呼ぶか** をまとめるツールです。ほかのツールとは別のページで、データも別々に保存されます。執筆ツールのサイドバー下の「人物事典を開く」、ほかのツールの上部の「人物事典」、または `people/index.html` から開きます。

### 人物

- 「＋ 新しい作品」で作品を作り、「＋ 人物」で人物を登録します。右側の欄に入力すると自動で保存されます
- 最初からある項目：名前、読み、別名・愛称、年齢、所属・立場、外見、性格、一人称、口調の特徴、口癖、メモ
- 「作品の設定」で **項目の追加・名前の変更・並べ替え・削除** ができます（「名前」以外）。「長文」にすると複数行で書ける欄になります
- 上の検索欄で、名前・読み・別名などすべての項目から探せます（ひらがな・カタカナの違いは区別しません）
- 「絞り込み」にした項目（最初は「所属・立場」）は、上の欄で値を選んで絞り込めます。`商店、町内会` のように `、` で区切ると、どちらでも絞り込めます
- 人物の並び順は、詳細欄の ↑ ↓ で変えられます（呼び方表の並びも同じ順になります）

### 呼び方表

- 「呼び方表」で、**縦に呼ぶ側・横に呼ばれる側** を並べた表になります。マスを押すと、呼び方と補足（場面で変わるときなど）を入力できます
- 斜めのマスには、その人物の「一人称」が出ます
- **部・ルートで呼び方が変わるとき**：「作品の設定」で部・ルートを追加すると（年表ツールの年表から部の名前を読み込むこともできます）、上に「基本／第一部／…」の切り替えが出ます
  - 部を選んで入力した呼び方は、その部だけの呼び方になります（オレンジで表示）
  - その部で入力していないマスは「基本」の呼び方を薄い文字で表示します。「基本と同じにする」でその部だけの呼び方を消せます
- 人物の詳細欄の下にも、その人物が呼ぶとき・呼ばれるときの一覧が出ます（押すと入力できます）
- 検索・絞り込みは呼び方表にも効きます（絞り込んだ人物だけの表になります）

### 保存・書き出し・読み込み

- データはこのブラウザ内（IndexedDB の `noveltool-people`）にだけ保存され、リポジトリには含まれません
- 「JSON書き出し」で作品ごとに書き出し、「読み込み」で復元できます。同じ作品（作品IDが同じ）がすでにあるときは「上書きする」か「別の作品として追加」かを選べます

### 人物事典のJSON（読み込み用の書式）

記入例：[`people/sample.json`](people/sample.json)

```json
{
  "format": "noveltool-people",
  "version": 1,
  "work": { "id": "my-work", "title": "作品名" },
  "fields": [
    { "id": "yomi", "label": "読み" },
    { "id": "affiliation", "label": "所属・立場", "filter": true },
    { "id": "tone", "label": "口調の特徴", "type": "long" }
  ],
  "parts": [{ "id": "p1", "name": "第一部" }, { "id": "p2", "name": "第二部" }],
  "people": [
    { "id": "a", "name": "人物A", "values": { "yomi": "じんぶつえー", "所属・立場": "商店" } },
    { "id": "b", "name": "人物B" }
  ],
  "calls": [
    { "from": "a", "to": "b", "call": "Bさん" },
    { "from": "人物A", "to": "人物B", "part": "第二部", "call": "Bちゃん", "note": "第二部では親しくなっている" }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `work` | `title` 作品名。`id` を書くと、同じIDの作品があるとき上書きできます |
| `fields` | 人物の項目（「名前」以外）。`id`（省略可）、`label` 項目名、`type`：`"long"` で長文、`filter`：`true` で絞り込みに使う。`fields` を省略すると最初からある項目になります |
| `parts` | 部・ルート。`{ "id", "name" }` または名前だけの文字列（省略可） |
| `people` | 人物。`id`（省略すると `p1`, `p2`…）、`name` 名前、`values` 項目の値（キーは項目の `id` か項目名）。`values` に知らない項目名があると、項目として足します |
| `calls` | 呼び方。`from` 呼ぶ側・`to` 呼ばれる側（人物の `id` か名前）、`call` 呼び方、`note` 補足（省略可）、`part` 部・ルートの `id` か名前（省略すると「基本」） |

- 読み込むと、人物のIDは新しく作り直されます（呼び方は自動で付け替えます）

## 伏線管理（`clues/`）

伏線・手がかり・ミスリードを、張った話・回収した話といっしょに管理するツールです。ほかのツールとは別のページで、データも別々に保存されます。執筆ツールのサイドバー下の「伏線管理を開く」、ほかのツールの上部の「伏線」、または `clues/index.html` から開きます。

### 作品の設定

- 「＋ 新しい作品」で作品を作ります。**人物事典・年表・執筆ツールの作品** と連動させると、人物名と話のタイトルが候補に出ます（ほかのツールのデータは読むだけで、書き換えません）
  - 人物の候補：連動した人物事典の人物 → 年表のできごとの登場人物 → この作品で使った名前
  - 話の候補：連動した執筆ツールの作品の話（執筆ツールと同じ順）→ この作品で使った話
- 部（「読者に見せた部」で使います）を追加・並べ替えできます。年表を選んで部がないまま保存すると、年表の部をそのまま使います（「選んだ年表から部を読み込む」でも足せます）

### 登録

「＋ 伏線・手がかり」で登録します。一覧の行を押すと編集・削除できます。

- 内容、種類（伏線／手がかり／ミスリード）、状態（未回収／回収済み／保留）
- 張った話、回収予定の話、回収した話（候補から選ぶか、自由に入力）
- 読者に見せた部（複数可）、関わる人物（複数可。Enter または候補を押して追加）、メモ
- 「回収した話」を入れると状態が「回収済み」に、消すと「未回収」に自動で変わります（状態を自分で押したときはそのまま）

### 一覧と絞り込み

- 張った話の順に並びます（執筆ツールと連動していれば、その話の順）
- 上の欄で絞り込めます：状態（**未回収だけ** など。件数つき）、種類、部（その部で読者に見せたもの）、人物、**話**（その話で張る・回収予定・回収したもの。どれに当たるかを印で表示）、内容・メモの検索。「条件を戻す」ですべて表示

### 保存・書き出し・読み込み

- データはこのブラウザ内（IndexedDB の `noveltool-clues`）にだけ保存され、リポジトリには含まれません
- 「JSON書き出し」で作品ごとに書き出し、「読み込み」で復元できます。同じ作品（作品IDが同じ）がすでにあるときは「上書きする」か「別の作品として追加」かを選べます。連動先は、ほかのツールの作品名で探してつなぎ直します

### 伏線管理のJSON（読み込み用の書式）

記入例：[`clues/sample.json`](clues/sample.json)（年表・人物事典の記入例と同じ人物名を使っています）

```json
{
  "format": "noveltool-clues",
  "version": 1,
  "work": { "id": "my-work", "title": "作品名", "peopleTitle": "人物事典の作品名", "timelineTitle": "年表の名前", "novelTitle": "執筆ツールの作品名" },
  "parts": ["第一部", "第二部"],
  "clues": [
    {
      "text": "店の看板が一枚だけ新しい",
      "kind": "伏線",
      "status": "未回収",
      "planted": "第1話",
      "shownParts": ["第一部", "第二部"],
      "payoffPlan": "第5話",
      "people": ["人物B"],
      "memo": "メモ"
    }
  ]
}
```

| 項目 | 内容 |
|---|---|
| `work` | `title` 作品名。`id` を書くと、同じIDの作品があるとき上書きできます。`peopleTitle`・`timelineTitle`・`novelTitle`（省略可）は連動させる人物事典・年表・執筆ツールの作品名 |
| `parts` | 部の名前の配列（省略可。`shownParts` に出てくる名前は自動で足します） |
| `clues[].text` | 内容（必須） |
| `clues[].kind` | `伏線`・`手がかり`・`ミスリード`（`foreshadow`・`clue`・`misdirect` でも可。省略すると伏線） |
| `clues[].status` | `未回収`・`回収済み`・`保留`（`open`・`done`・`hold` でも可。省略すると、`payoff` があれば回収済み、なければ未回収） |
| `clues[].planted` / `payoffPlan` / `payoff` | 張った話・回収予定の話・回収した話（話のタイトル。省略可） |
| `clues[].shownParts` | 読者に見せた部の名前の配列（`"第一部、第二部"` のような文字列でも可） |
| `clues[].people` | 関わる人物の名前の配列（文字列でも可） |
| `clues[].memo` | メモ |

## 手元で使う

このフォルダの `index.html` をブラウザで開くだけで動きます。
（ただし保存場所はURLごとに分かれるため、手元のファイルで書いた原稿と、公開ページで書いた原稿は別々になります）

## GitHub Pages で公開する手順

1. このブランチの変更を `main` に取り込みます（プルリクエストを作って Merge する）。
2. GitHub でリポジトリを開き、**Settings** → 左メニューの **Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** で `main`、フォルダで `/ (root)` を選び、**Save** を押します。
5. 1〜2分待ってページを再読み込みすると、上部に公開URLが表示されます。
   通常は `https://<ユーザー名>.github.io/noveltool/` です。
6. スマホではそのURLを開き、共有メニューから「ホーム画面に追加」するとアプリのように使えます。

補足：

- 無料プランで Pages を使うには、リポジトリを **Public（公開）** にする必要があります。公開されるのはツールのプログラムだけで、書いた原稿はブラウザの中にあるため、ほかの人からは見えません。
- ツールを更新したときは、`main` に変更を取り込めば自動で公開ページにも反映されます。
- 公開URLが変わると保存場所も変わります（ブラウザはURLごとに保存するため）。URLを変えるときは先に書き出してください。
